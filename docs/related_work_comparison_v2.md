## 1. Related work (report-ready text)

**Zero-shot classification and prompt sensitivity.** CLIP \cite{radford2021clip} showed that contrastive pretraining on image-text pairs transfers zero-shot to many classification datasets, and that prompt engineering and ensembling several templates improve accuracy. CoOp \cite{zhou2022coop} documented that a slight change in prompt wording can change accuracy substantially and proposed learning continuous prompt context from labeled examples. We do not learn prompts: we fix a set of seven templates before evaluating the remaining datasets and only measure sensitivity and simple ensembling, so no target labels are used for prompt selection.

**Compositional reasoning: relations, counting and negation.** ARO \cite{yuksekgonul2023aro} built more than 50,000 test cases and showed that vision-language models (VLMs) have poor relational understanding, bind attributes to the wrong objects and are largely insensitive to word order, behaving like bags of words; the authors attribute this partly to retrieval objectives that can be solved without composition. Winoground \cite{thrush2022winoground} pairs two images with two captions that contain the same words in a different order and finds that no tested model is much better than chance. SugarCrepe \cite{hsieh2023sugarcrepe} showed that several earlier compositionality benchmarks can be solved by text-only models and proposed fluent hard negatives with reduced bias. For spatial relations, What'sUp \cite{kamath2023whatsup} controls the scene so that only the relation changes and finds that 18 VLMs perform poorly (for example 56% against 99% for humans), noting that large pretraining corpora contain little reliable spatial supervision; VSR \cite{liu2023vsr} collects more than 10k natural image-text pairs over 66 relation types and reports a gap between humans (above 95%) and models (around 70%), with orientation relations particularly hard. For counting, Paiss et al. \cite{paiss2023countbench} show that CLIP fails to count and introduce a counting-contrastive fine-tuning loss together with the CountBench benchmark. NegBench \cite{alhamoud2025negbench} evaluates negation over 79k examples and 18 task variations and finds that modern VLMs often perform at chance, improving them by fine-tuning on synthetic negated captions.

**Region-based spatial inference.** ReCLIP \cite{subramanian2022reclip} repurposes CLIP for zero-shot referring expression comprehension: it scores object proposals by cropping and blurring image regions, and because controlled synthetic experiments showed that CLIP is largely incapable of spatial reasoning off the shelf, it adds a rule-based spatial relation resolver. RegionCLIP \cite{zhong2022regionclip} instead pretrains region-text alignment, arguing that image-level CLIP lacks fine-grained region alignment. Our half-canvas region splitting follows the same idea as ReCLIP, scoring image regions with CLIP and combining the scores with a geometric rule, so we do **not** present it as a new method. We use it as a test-time diagnostic: on mirrored image pairs it asks whether location information that the holistic score misses can still be read out of region-level CLIP scores, and we bound it with an oracle bounding-box rule.

**Multilingual and Vietnamese vision-language models.** Multilingual extensions replace or distill the text encoder: M-CLIP \cite{carlsson2022mclip} trains multilingual text encoders aligned to CLIP by teacher learning, and AltCLIP \cite{chen2023altclip} swaps the text encoder for XLM-R and reaches performance close to CLIP on most tasks while adding other languages. SigLIP \cite{zhai2023siglip} replaces the softmax contrastive loss with a pairwise sigmoid loss and is a common baseline, including in ViCLIP-OT \cite{tran2026viclipot}, a recent Vietnamese image-text retrieval model (preprint). These works train new models; we instead measure what happens when Vietnamese prompts are given to the original English checkpoint, and relate the drop to subword tokenization \cite{sennrich2016bpe}.

**What this project adds.** The failure modes themselves are known. Our contribution is a set of controlled diagnostics on a single checkpoint: recognition controls on the same images for counting, spatial relations and negation; mirrored-pair consistency on COCO \cite{lin2014coco}; an object-recognition control on the natural images (T1); an ablation that removes center-crop loss and an oracle geometric baseline (T2); human label verification with inter-annotator agreement \cite{cohen1960kappa}; an unseen held-out image set; and hybrid Vietnamese prompts that separate the class name from the sentence frame. Confidence intervals use source- or group-level bootstrap \cite{efron1979bootstrap} and Wilson intervals \cite{wilson1927interval}.

## 3. Positioning against ReCLIP (instructor comment 1)

- **Same principle:** CLIP scores on image regions plus a geometric rule. ReCLIP uses cropped or blurred object proposals and a spatial relation resolver for referring expressions; we use four fixed half-canvases and a difference-of-differences rule for a two-object relation.
- **Not claimed:** novelty of region-based inference, or that the CLIP encoder "understands" relations better when cropped.
- **What we measure instead:** (i) holistic CLIP fails left/right even when it recognizes both objects (T1: 86.48% recognition, 51.01% relation on fully recognized images); (ii) the failure is not caused by center-crop loss (T2: full-image padding changes holistic accuracy by 0.00 points, CI [-3.06, 3.06]); (iii) region readout approaches an oracle geometric ceiling on Set B (93.37% vs 99.49%) and transfers to an unseen set (89.00%); (iv) it fails where its geometric assumption fails (two objects in the same half).
